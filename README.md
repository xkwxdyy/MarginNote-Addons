# MarginNote Addons

MarginNote 插件的介绍、开发入口与公开反馈集中在该仓库。

| 项目 | 源码与反馈 |
| --- | --- |
| Knowledge Base | [MNKnowledgeBase](https://github.com/xkwxdyy/MNKnowledgeBase) |
| Comment Manager | [MNCommentManager](https://github.com/xkwxdyy/MNCommentManager) |
| 通用开发工具 | [MarginNote-Addon-Tooling](https://github.com/xkwxdyy/MarginNote-Addon-Tooling) |
| MNPinner、MNLiterature | 源码与研发记录保存在私有仓库；公开反馈可以在该仓库提交 |

免费插件的问题优先提交到对应仓库。公开反馈请注明插件版本、MarginNote 版本、操作系统、复现步骤和预期结果，附件请使用经过脱敏的最小示例。

工作区中的项目分别使用 Git 管理。公共入口仓库只保存经过审查的说明和模板，具体目录与构建约定见[开发说明](docs/DEVELOPMENT.md)。已有用户分发渠道继续沿用。
